## 🔍 About the Project

**Hugging Face Models Explorer** is a sleek and efficient Streamlit-based app that allows users to:

- 🔎 Search models by keywords (e.g., "LLaMA", "BERT", "GPT")
- 📊 Sort results by download count or alphabetically
- 📥 Instantly view top Hugging Face models with download stats
- 💡 Built for quick discovery, comparison, and inspiration

Whether you're a beginner or a seasoned ML engineer, this tool can simplify your Hugging Face model exploration experience.

---

## 🚀 Features

- **Real-time Search**: Query Hugging Face’s model hub instantly
- **Sort by Popularity**: View the most downloaded models first
- **Simple UI**: Clean, dark-themed interface powered by Streamlit
- **Responsive Design**: Works on desktop and mobile
- **Up to 100 Models Listed**: Smart limiting for performance
